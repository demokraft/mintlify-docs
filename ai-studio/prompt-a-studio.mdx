## Introduction to Prompt a Studio

Prompt a Studio is a feature within Demokraft AI Studio designed to simplify video production using AI technology.

## Purpose of Prompt a Studio

Prompt a Studio transforms simple product information into a fully editable Demokraft Studio video project through AI-powered automation.


## Automated Video Creation Workflow

By providing a product description or website URL, the system automatically generates storyboards, scenes, motion graphics, layouts, visuals, brand styling, and narration. Users retain control by reviewing and editing each stage before final video production.


## Outcome: Editable Video Projects

The output is a fully editable Demokraft AI Studio project—not just a rendered video—allowing customization to fit specific needs.


## Getting Started Methods

Users can initiate video creation by either supplying a website URL or entering a detailed prompt with product and video specifics.


## Accessing Prompt a Studio

From the Demokraft AI app home screen, select Prompt a Studio, then choose between the website-based or prompt-based start options.

## Storyboard Outline Generation

The AI analyzes input data, extracts relevant information, and produces a storyboard outline for user review and feedback before detailed creation.

<Note>
  Please note it might take few minutes to generate Storyboard outline and details.
</Note>


## Storyboard Detail Contents

The detailed storyboard includes scene-by-scene descriptions, visuals, voice-over scripts, and requires processing time to analyze assets thoroughly.


## Reviewing and Approving Storyboards

Users can evaluate the generated outline, provide feedback in natural language, regenerate if necessary, or approve to proceed with detailed scene creation.
